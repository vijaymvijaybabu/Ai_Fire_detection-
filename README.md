# 🔥 Industrial AI Safety Monitoring System

An advanced real-time Industrial AI Safety Monitoring System that leverages Computer Vision and Artificial Intelligence to detect fire, smoke, hazardous situations, and safety threats inside industrial environments. The system provides real-time monitoring, automatic alerts, event recording, and intelligent threat analysis using YOLOv8 and OpenCV.

---

## 🚀 Overview

Industrial accidents can lead to severe financial losses and safety risks. This project uses Artificial Intelligence to continuously monitor surveillance cameras and automatically detect hazardous situations before they become critical.

The system combines multiple AI models including object detection, fire detection, smoke detection, scene analysis, and threat evaluation into one intelligent monitoring pipeline.
